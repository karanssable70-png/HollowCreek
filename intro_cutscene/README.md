# Intro cutscene

This cutscene is kept separate from the playable game. It uses the four supplied images with slow zooms, crossfades, letterbox bars, and short story captions.

## Preview in Godot

1. Open `res://intro_cutscene/intro_cutscene.tscn`.
2. Press **F6** to run the current scene.

The shots play in order and advance automatically. Press **Space**, **Enter**, or **E** to move to the next shot. Press **Esc** or choose **Skip Intro** to go straight to the existing main game. After the final shot, choose **Enter the Village**.

The project startup scene remains `res://main.tscn`; this intro does not replace or edit it.
